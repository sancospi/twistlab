# Security

If you find a vulnerability in TwistLab (the app at twistlab.app or this code), please report it privately: open
**Security → Report a vulnerability** in this repository (GitHub's private reporting), not a public issue. You'll get an
answer as soon as possible, and credit if you want it once it's fixed.

Si encuentras una vulnerabilidad, avísala en privado desde **Security → Report a vulnerability** en este repositorio, no
en un issue público.
